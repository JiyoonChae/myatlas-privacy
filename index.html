MyAtlas

개인정보처리방침

앱: MyAtlas · 패키지명: com.jyc.myatlas
초안 작성일: 2026년 11월 2일

출시 준비용 초안입니다. 정식 배포 전에 운영자 정보와 문의 처리 기준을 확정하고 이 문서를 갱신합니다.

MyAtlas는 사용자가 방문한 여행지를 기록하고 지도와 영상으로 돌아볼 수 있는 Android 앱입니다. 이 문서는 앱에서 처리하는 정보, 외부 서비스의 이용, 정보 보관 및 삭제 방법을 설명합니다.

핵심 안내
  • 회원가입과 로그인이 없으며, 광고 SDK 및 Firebase Analytics를 사용하지 않습니다.
  • 여행 기록은 기기의 앱 전용 저장공간에 보관합니다. Android 백업을 사용하면 기기 밖에도 백업될 수 있습니다.
  • 도시 검색과 Google 지도 이용 시 외부 서비스와 통신합니다.
  • 여행 영상은 기기에서 생성하여 갤러리에 저장합니다.

1. 처리하는 정보와 목적

기능별 정보 처리
기능정보목적 및 처리 위치
여행 기록여행 제목, 방문 국가·도시, 장소 좌표, 여행 기간·방문 날짜, 방문 순서, 기록 식별자기록 저장·편집·조회, 여행 통계, 경로 재생을 위해 기기 내 Room 데이터베이스에서 처리합니다.
사진으로 도시 가져오기선택한 사진의 위치·촬영 날짜 메타데이터와 도시 후보사진의 촬영 날짜를 방문일로 사용하고 좌표를 읽어 Android Geocoder로 도시를 찾습니다. 좌표는 기기의 지오코딩 서비스 제공자에게 전송될 수 있습니다. 사진 자체는 앱에 저장하지 않습니다.
도시 검색입력한 도시·장소 검색어, 검색 결과의 장소명·국가·좌표Android Geocoder를 이용해 위치 후보를 찾습니다. 검색어는 기기의 지오코딩 서비스 제공자에게 전송될 수 있습니다.
Google 지도지도 요청 정보, IP 주소, 기기·SDK 정보, SDK 식별자, 오류·진단 정보, 지도 조작 정보지도 표시 및 Google 서비스 운영·개선을 위해 Google Maps SDK가 정보를 처리할 수 있습니다. 자세한 내용은 아래 외부 서비스 항목을 참고해 주세요.
영상 저장영상에 표시할 여행지·경로·여행 제목·기간 등의 기록, 생성된 MP4기기 내에서 영상을 생성하여 Movies/MyAtlas에 저장합니다. 앱 운영자의 서버로 업로드하지 않습니다.
Android 백업·기기 이전여행 기록과 방문 도시가 포함된 앱 데이터베이스사용자의 기기 설정 및 Android 백업·이전 기능에 따라 백업 제공자 또는 새 기기로 전달될 수 있습니다.

앱 운영자는 여행 기록을 수집하는 자체 서버를 운영하지 않습니다. 앱은 이름, 전화번호, 주민등록번호나 로그인 정보를 입력받지 않습니다.

2. 외부 서비스와 정보 전송

Google Maps SDK for Android

Google 지도를 표시할 때 Google 서비스와 통신합니다. Google의 SDK 안내에는 기기 및 SDK 관련 요청 정보, IP 주소, SDK 전용 가명 식별자, SDK 오류·진단 정보 수집이 설명되어 있습니다. 앱은 지도 카메라 이동·확대 기능을 사용하며, 이 과정의 지도 조작 정보도 처리될 수 있습니다. 지도에 표시할 지역의 좌표를 SDK에 전달합니다. 이것은 사용자가 기록한 여행지이며 현재 GPS 위치를 자동 수집한 정보가 아닙니다.

외부 서비스의 세부 처리·보관·삭제 기준은 제공자의 정책을 따릅니다.

  • Google 개인정보처리방침
  • Google Maps SDK 데이터 처리 안내

Android Geocoder

도시 검색 화면에서 입력이 잠시 멈추면 검색어로 위치 후보를 요청합니다. 여러 도시를 한 번에 추가할 때에도 도시별로 위치 검색을 요청합니다. Geocoder는 기기에 설정된 구현을 사용하므로 서비스 제공자와 세부 처리 방식은 기기 환경에 따라 달라집니다. 검색어와 요청 처리에 필요한 통신 정보가 해당 제공자에게 전달될 수 있습니다.

Android 자동 백업 및 기기 이전

기기에서 자동 백업을 사용하는 경우 여행 데이터베이스가 기기에 설정된 백업 서비스에 저장될 수 있습니다. 기기 이전 시에도 데이터베이스가 전달될 수 있습니다. 앱 운영자가 백업본을 열람하거나 복원하는 기능은 없습니다. 앱의 백업 규칙은 데이터베이스를 대상으로 하며 사진과 내보낸 영상은 포함하지 않습니다. 갤러리 앱의 별도 사진·영상 백업 기능은 사용자가 이용하는 서비스의 설정을 따릅니다.

이 안내 페이지

이 페이지는 GitHub Pages에서 제공됩니다. 페이지 접속 시 호스팅 제공자가 IP 주소 등 접속 정보를 처리할 수 있습니다. 페이지 자체에는 광고, 방문 분석 스크립트, 입력 양식을 넣지 않았습니다.

GitHub 개인정보처리방침

외부 서비스가 처리하는 정보는 제공자의 정책과 서비스 환경에 따라 국외에서 처리될 수 있습니다.

3. 앱 접근 권한

앱은 도시 검색과 지도 이용을 위해 인터넷 및 네트워크 상태 접근 권한을 사용합니다. 사진으로 도시를 가져올 때 선택한 사진의 원본 위치 정보에 접근하는 권한을 요청합니다. 현재 GPS 위치, 연락처, 카메라, 마이크 및 사진·영상 전체를 읽는 권한은 요청하지 않습니다. 영상은 Android의 MediaStore를 이용해 앱이 생성한 파일을 저장합니다.

4. 보관 기간과 삭제 방법

  • 여행 기록: 사용자가 삭제하거나 앱 데이터를 지울 때까지 기기에 보관합니다. 여행 상세 화면에서 메뉴의 ‘여행 기록 삭제’를 선택하면 해당 기록이 현재 앱 데이터베이스에서 삭제됩니다.
  • 기기 내 앱 데이터 전체: Android 설정에서 MyAtlas의 저장공간 데이터를 지우거나 앱을 삭제하면 기기 내 앱 전용 데이터가 제거됩니다. 과거 버전에서 이전된 데이터가 있는 경우 호환용 로컬 사본이 남아 있을 수 있으며, 앱 데이터 전체 삭제 시 함께 제거됩니다.
  • 내보낸 영상: 앱 데이터 삭제나 앱 제거와 별개로 갤러리에 남을 수 있습니다. 갤러리 또는 파일 앱에서 직접 삭제하고, 갤러리의 휴지통·클라우드 백업도 별도로 확인해 주세요.
  • 백업본: 앱에서 기록을 지워도 기존 백업본까지 즉시 지워지는 것은 아닙니다. 백업 서비스의 설정에서 관리하며, 재설치나 기기 이전 시 백업본의 기록이 복원될 수 있습니다.
  • 외부 서비스 처리 정보: Google, 기기의 Geocoder 제공자, 백업 제공자 및 호스팅 제공자의 보관·삭제 정책을 따릅니다.

여행 기록은 앱에서 직접 확인·수정·삭제할 수 있습니다. 자체 계정이 없어 회원 탈퇴 절차는 없습니다. 앱 운영자는 사용자의 기기에 저장된 기록을 원격으로 조회하거나 삭제할 수 없습니다.

5. 정보 보호와 사용자의 선택

여행 데이터베이스는 Android의 앱 전용 저장공간에 보관됩니다. 저장된 파일이 별도의 앱 자체 암호화로 보호된다고 보장하지 않으며, 기기 잠금과 운영체제의 보안 설정을 함께 사용해 주세요. 외부 서비스와의 통신 및 백업의 보호 방식은 해당 서비스와 기기 환경을 따릅니다.

기기의 백업 설정에서 백업 사용 여부를 관리할 수 있습니다. 도시 검색과 Google 지도 기능은 네트워크 연결이 필요합니다. 저장한 영상을 다른 앱이나 서비스로 공유하면 해당 서비스의 개인정보 처리 기준이 적용됩니다.
